# Recorded certification results

Generated by `cargo run -p persistant-opendal --example opendal_matrix` and `cargo run -p persistant-sqlx --example sqlx_matrix`; CI regenerates them on Linux and fails if they differ. The exception is `opendal-machine.tsv` (`blob.durable`, measured by a power cut of a Hyper-V guest): it cannot be regenerated on a hosted runner, so the `machine-durability` run writes its rows (`machine_vm_blob row`, artifact `machine-durability-matrix`) and `scripts/machine-durability/compare-matrix.ps1` compares them with the checked-in file; the rows are added from that artifact, never by hand. Format: `docs/DESIGN-KINDS.md` section 2.4, read with `persistant_core::Matrix::parse`.
